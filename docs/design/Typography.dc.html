Typography
Atkinson Hyperlegible · Braille Institute
A typeface chosen for the same reason the contrast floors are numbers. Its letterforms are drawn to be told apart rather than to look even — which is a strange goal for a display face and exactly the right one for a system whose whole job is dense rows of data someone has to read correctly the first time.

Every one of those pairs is a real defect report somewhere: a paint code read wrong, a version string retyped wrong, an identifier copied wrong. The face solves it in the shape rather than asking the interface to compensate with size or spacing.
