Badge tone comes from a map. Six tones, six entries in classMaps.ts. No class name is ever assembled from a variable, so every class the build sees can be found by searching for it.
An interactive card takes a left bar, not a lift. There is no shadow to raise it with, so the whole card gains a 3 px accent edge and a recessed fill — the same move a selected row makes.
Empty states are statements, not illustrations. A count, a sentence saying what is missing, and one action that fixes it. No mascot, no spot drawing.
