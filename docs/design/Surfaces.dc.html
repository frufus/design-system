Badge tone comes from a map. Six tones, six entries in classMaps.ts. No class name assembled from a variable anywhere, so every class the build sees can be found by searching for it.
A card is a container, not a component family. Header, body and footer are slots. It gains a border and a pointer only when the whole card is one link or button.
Empty states are statements, not illustrations. A sentence that says what is missing and one action that fixes it. No mascot, no spot drawing.
