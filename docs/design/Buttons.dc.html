The segment is a layout, not a variant: three ordinary buttons sharing borders, rounded only at the two outer corners. Each keeps its own 44 px target.
Two rules worth stating
Loading keeps the label. The spinner is added, the text is not replaced, so the button does not change width mid-action and a screen reader still reads what it does. It reports aria-busy and stays focusable.
Disabled is flat, not faded. Opacity would let each variant's colour leak through and break contrast differently in every appearance; a dedicated pair of tokens keeps it measurable — 4.47 in light, 3.52 in dark.
