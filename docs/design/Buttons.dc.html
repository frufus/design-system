An icon-only button is square at the row height and takes its accessible name from a prop, never from the glyph.
Loading keeps the label. The spinner is added, the text is not replaced, so the button does not change width mid-action and a screen reader still reads what it does. The control reports aria-busy and stays focusable.
Disabled is flat, not faded. Opacity would let the variant's colour leak through and break contrast differently in each appearance; a dedicated pair of tokens keeps it measurable.
